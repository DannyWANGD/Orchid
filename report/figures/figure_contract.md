# 图表约定

- **架构图**说明输入、张量维度、GPT 块、两个残差和绑权；不画未实现的组件。
- **预训练曲线**按实际累计有效 token 显示训练 NLL 和完整验证集 NLL，初始验证点是随机模型。报告验证曲线何时停止改善；不能把 NLL 下降解释为会写新诗。
- **SFT 曲线**显示三个微调种子各自的验证 NLL，同一起点为共享预训练权重；分开保存曲线原值。NLL 的目标掩码与预训练不同，两组曲线不做横向数值比较。
- **任务对比图**只用冻结的无参考诗题，分列四句五字、全词命中和联合达标；原始 R1/R2 与换词或规则约束实验分开说明。若展示误差，说明它是训练种子的标准差或按诗题重采样的区间。
- 图的源数据随报告保留。导出矢量 PDF/SVG，重复运行不手工改图。正文引用明确区分测量、展示样例和独立人评。
