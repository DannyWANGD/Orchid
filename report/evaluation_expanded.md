# 92M 唐宋版：封存自动评估

先用固定唐诗 validation 的 90 道题 × 3 个采样种子选模型。按「四句各五字、用全指定词、未与训练整首或长诗四句片段精确匹配」排序，入选唐宋 SFT 种子 2028（95/270）。另外两个种子是 66/270 和 79/270。交付版本已在运行下面测试前锁定；[选型记录](evidence/scale-model-selection.json)保留未入选模型的分数。

下面各组均在同一张 RTX 4080 SUPER 用 FP32 推理，同一批 50 道新题，每题采样 3 次。补充参考 NLL 来自另外 100 首唐诗 test 留出诗作，按正文、标点及 EOS 共 2,500 个目标计损失。跨设备采样可能不同，14M 的历史 CPU 结果见[基线报告](evaluation_baseline.md)，不能用不同设备数据算模型间收益。

微调相对同一个唐宋预训练检查点，联合率提高 13.3 个百分点，按 50 道诗题分组重采样的 95% 区间为 +6.7 到 +20.7 个百分点；三个唐宋 SFT 种子均值 12.22%，样本标准差 1.39 个百分点。选定模型的 20 次联合成功全部来自单词题（20/48）；两词、三词题各 0/51。实际输入换词后，对原题联合成功降为 1/150；对替换题的所有词命中为 19/150。100 道留出诗派生题上联合成功 122/300。扩容的显著进步在语言建模，不能说它的任意条件创作已稳定超过唐诗 10 轮版。

149 条合规格的交付模型原始输出中，偶句同韵 61、不合 40、待判 48；可判覆盖 101/149，通过率 61/101，两者均应给出。四个严格平仄常格为 0 合、140 不合、9 待判，只是规则诊断。在唐宋训练语料索引中未发现该批合规格输出整首、四句片段或规则近重复。6 个边界题每个重复 3 次，18 次均明确拒绝，不计入正常诗题的分母。

原始生成的例子（RTX 4080 SUPER）：

- M007、种子 11、题「青山」：「白馬馳千里，青山繞一村。人行古城外，山在白雲根。」格式和关键词通过，「村／根」偶句通过；仍可讨论收束与用词。
- M017、种子 11、题「霜、孤舟」：「江闊魚龍集，江清魚蟹肥。平生多感慨，誰與共清暉。」四句成形，但两个词都没用，第三句转折也较突兀。开独立的强制关键词模式会出现「平孤舟楫處」这类夹词生硬的句子，100% 规则通过不等于写得好。
- M003、种子 11、题「梧桐」：「秋夜同梧桐，秋風入梧桐。秋來桂枝下，秋至梧葉中。」字面命中，但「秋」与「梧桐」反复、意象发展少。
- M001、种子 33、题「霜」：「霜中菊初發，霜後菊始繁。獨有歲寒節，獨有霜中根。」词和字数均通过，偶句「繁／根」的读法影响韵部判断，自动记待判。
- M045、种子 33、题「古道、落日、歸路」：「秋花滿路，秋草長門。秋色侵衣冷，山風入戶清。」前两句各四字，格式不合。
