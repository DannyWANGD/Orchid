# 格律规则的文献复核

这份复核由 Codex 查原典、辞书和固定韵表完成。它解释程序在哪些样例上会误判或待判；**未替代《清单》OPT-02 要求的独立专业读者抽查**。所有例子按原字形检查，正式自动分数不重算。平声/仄声说的是古韵；普通话读音只帮助确定歧义字的词义。

| 样例 | 查到的依据 | 对自动分数的解释 |
|---|---|---|
| 李端《聽箏》 | [王力《诗律》第五节](https://www.aisixiang.com/data/98039.html)用这首诗说明五言律绝的平起式。项目韵表将「前／弦」均列为下平一先 | 通过平仄常格及押韵，可作为正例 |
| 《登鸛雀樓》 | 同节把这首诗作为仄起式示例；「流／樓」同属下平十一尤，「欲」属入声二沃 | 第三句首字「欲」为仄，与程序要求的字面全平起句型不完全相合。王力仍以全诗举例，这是程序逐字匹配范围过窄的现成反例 |
| M007/11，「村／根」 | [《欽定叶韻彚輯》卷七](https://zh.wikisource.org/wiki/%E6%AC%BD%E5%AE%9A%E5%8F%B6%E9%9F%BB%E5%BD%9A%E8%BC%AF_%28%E5%9B%9B%E5%BA%AB%E5%85%A8%E6%9B%B8%E6%9C%AC%29/%E5%8D%B707)与项目韵表均列入元韵 | 偶句同属上平十三元。第三句「人行古城外」按行走义读「行」为平，整句为「平平仄平仄」，属于王力列出的特定句式，程序却只收逐字常格；这项诊断不足以判整首是否律绝 |
| M001/33，「繁／根」 | [《重編國語辭典修訂本》「繁」](https://dict.revised.moe.edu.tw/dictView.jsp?ID=610)在 fán 项下列出茂盛义；《欽定叶韻彚輯》卷七在元韵下也列「繁」的多义项 | 据「菊始繁」的语境，倾向按茂盛义归元韵，可与「根」相押。韵表还有寒韵条目；自动结果仍为待判 |
| M004/11，「病／浄」 | [教育部《異體字字典》](https://dict.variants.moe.edu.tw/dictView.jsp?ID=24255)将「浄」收为「淨」的异体；项目韵表把「病／淨」均列作去声二十四敬 | 若仅为古韵说明而通读为「淨」，二字同仄韵，仍不满足实验规定的偶句同**平**韵。原自动分数保留字形缺失导致的待判 |
