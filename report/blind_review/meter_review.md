# 格律抽查材料

请熟悉古典诗律的读者从下面的例子核对字数、偶句用韵及平仄。程序按四套逐字常格处理，读音、拗救和邻韵问题请写明所依据的版本或规则。参与匿名诗歌质量评分的读者先提交盲评表，再打开本页。

| 样例 | 程序口径 | 请核对 |
|---|---|---|
| 李端《聽箏》所用版本 | 平起、首句不入韵的逐字常格通过 | 卷本与字形，偶句「前／弦」韵部 |
| 《登鸛雀樓》所用版本 | 平水韵偶句同韵，逐字平仄常格未过 | 「欲」所在位置是否允许变通 |
| 唐宋 92M，M007/11：「白馬馳千里，青山繞一村。人行古城外，山在白雲根。」 | 四句五字，偶句「村／根」同韵 | 查韵部；同韵与是否律绝分开 |
| 唐宋 92M，M001/33：「霜中菊初發，霜後菊始繁。獨有歲寒節，獨有霜中根。」 | 偶句韵脚待判 | 按上下文定「繁／根」读音和韵部 |
| 唐宋 92M，M004/11：「秋霖生秋凉，秋雨洗我病。一官事業成，此事頗清浄。」 | 韵表的「浄」字形缺失，待判 | 是否可用异体字「淨」对照；另记依据 |
| 新默认版，M028/22：「古路斜陽下，高樓遠樹邊。登樓殘月暮，一一是秋天。」 | 偶句同韵，逐字常格通过 | 检查「邊／天」及仄起首句不入韵 |
| 新默认版，M001/22：「霜風吹欲盡，庭樹未全凋。一夕西園裏，何人獨自飄。」 | 偶句同韵，逐字平仄待判 | 给定语境下多音字如何取平仄 |
| 新默认版，M001/11：「霜蟹肥堪釀，霜螯美可烹。一千頭上雪，三百首陽英。」 | 偶句同韵，逐字平仄不合 | 检查「烹／英」韵部及第 1、3、4 句首字是否可以变通 |

公式及统计见[扩容评估](../evaluation_expanded.md)、[原 92M 常格诊断](../evidence/meter-expanded.json)和[新版常格诊断](../evidence/meter-prosody.json)。
