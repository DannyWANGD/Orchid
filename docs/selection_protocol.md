# 扩容版本选择与报告边界

从未用于测试的 166 对唐诗监督 validation 计算响应 NLL；从其固定顺序等距选 90 道诗题，采样种子 11、22、33，默认参数 0.8 / top-k 50 / 64 token。大模型和基线共用这两套验证输入，且全部按训练源查整首 / 长诗片段 / 近重复。冻结新诗题、留出参考诗题均不参与下面的选择。

1. 每个正式训练 run 的 `best.pt` 用验证 NLL 确定。分别记录后续轮次何时停止和 `last.pt` 的指标。
2. 交付演示版对候选 run 以 90 道验证诗题的「完整五言四句、用全关键词且与训练诗无精确/长诗片段复现」计数选择。并列时先取较低的验证正文 NLL，再取较小参数量；三种子结果须同时报告。自动联合率不能用作人工文学质量结论。
3. 一次性评估登记版本。报告同一套 50 道无参考诗题和 100 道留出原诗题；是否是新组合由各版本自己的训练配对确定。七言、完整律绝约束、模型裁判和外部云设备非必做；盲评依赖独立评阅者。
4. 如果想另试关键词约束等工程改善，使用明确命名的解码增强，并报告原始模型对照，不能把后处理提升算成训练提升。
