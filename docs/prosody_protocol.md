# 五言四句与押韵改进方案

盲评回件提供了两条可独立复现的问题线索。五言任务需要写满四句，每句五个汉字。押韵要求取第二、第四句末字，两字不同，且在固定版本的《平水韻》表中各自只有一个归部、同属平声一部。首句是否入韵、古今音变、借韵和平仄变格另行分析。歧义字保留为未知。此口径便于工程验收，范围比专家判断窄。[王力《诗律》](https://www.aisixiang.com/data/98039.html) · [《平水韻》](https://zh.wikisource.org/zh-hant/%E5%B9%B3%E6%B0%B4%E9%9F%BB)

## 数据与权重

从原交付 92M 的 `sft-tang-song-92m-2028/best.pt` 继续监督训练，重新初始化优化器。唐宋语料、字符表、分组切分和训练集来源见[语料契约](data_contract.md)。只在已校验的 `data/processed/tang-song/sft/train.jsonl` 中选样。先按固定种子抽 4,096 条普通样本作为对照，再按对照中的一词、二词、三词配比，从可靠同韵的训练样本抽取同样多的处理组。两组各 6 轮，保持优化参数、训练种子、样本数和响应 token 预算一致。子集指纹及各类样本量随检查点保存。验证集使用原封存 SFT 验证集，独立保留原 50 道测试题与旧盲评回件。

## 推理与比较

生成时限制每句长度、标点和结束符，第 2 句由模型在可靠平声字中选择韵脚，第 4 句在同韵部的其余字中选择。关键词用多个句内布局生成候选，若词已经自然出现，可保留模型的选择。候选以原始模型的平均 token 对数概率排序，并扣除重复短语和重复整句。九歌系统也把诗体长度、平仄和押韵要求显式传给生成模块。[Guo 等，ACL 2019](https://aclanthology.org/P19-3005/)

训练效果只在原始采样下比较。取原验证集均匀分布的 90 道题，采样种子 11、22、33。两支续训按固定步数的末检查点比较。仅当韵律续训的可靠押韵数高于普通续训及原交付模型、结构与关键词同时命中数未下降、三项全过数未下降、训练集整首重合数未上升时，切换交付权重。选择完权重，再用测试题比较原始、仅字数、字数加押韵，以及再加关键词的方式。所有比例以实际生成总数为分母，另报未知、重复韵脚、训练集重合、重复整句和推理时延。旧盲评保持原 ID 与原诗；新实验中的自动通过率只反映各项可执行规则。
